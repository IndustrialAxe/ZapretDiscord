>

Если вы уверенно понимаете настройки исключений, лучше добавить исключение; при сомнениях отключите обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется
    * Владельцам роутеров Keenetic следует включить параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать неправильно

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/IndustrialAxe/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, распаковываемых через 7-Zip или PeaZip, этот пункт можно пропустить

4. Распакуйте архив в путь без кириллицы и специальных символов

5. Запустите необходимый файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для включения автозапуска используйте **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) - ручной запуск выбранной стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** - убрать стратегию и WinDivert из служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо запустить заново.**  
  В скобках отображается текущее состояние (включено/выключено).
  - **`IPSet Filter`** - выбрать режим обработки сервисов из `ipset-all.txt`.  
  Параметр полезен при проверке ресурса, который без zapret перестаёт открываться  
  В скобках показывается текущее состояние:
    - `none` - ни один IP не проверяется
    - `loaded` - IP сверяется со списком
    - `any` - фильтр применяется к любому IP  
  - **`Auto-Update Check`** - включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** - заменить используемый фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - получить свежую версию `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - выполнить проверку распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает вернуть работу приложения
  - **`Run Tests`** - открыть инструмент проверки стратегий:
    - `Standard tests` - тестировать сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/IndustrialAxe/zapret-discord-youtube/issues/522)

### Не подошла ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте содержимое открывшегося блокнота целиком
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированный текст в конец файла `hosts` или замените аналогичные строки, если вы уже добавляли их раньше
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Когда это не помогает, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/IndustrialAxe/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии могут устаревать.**
> Стратегия, которая работала раньше, со временем способна перестать работать после обнаружения её параметров.
> Здесь есть несколько вариантов обхода. Если ни один не даёт результата, создайте собственную стратегию на основе имеющейся и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- Проверьте остальные варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительные сведения есть в [#765](https://github.com/IndustrialAxe/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и настройки
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`, исправьте найденные ошибки и в конце выберите Y
- Удалите старый каталог zapret
- Загрузите свежую версию со [страницы релизов](https://github.com/IndustrialAxe/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если доступна галочка разблокировки, поставьте её, нажмите применить и ОК
- Распакуйте архив в новую папку в корне диска, без пробелов, кириллицы и специальных символов
- Запускайте разные `general`-скрипты и проверяйте ресурсы. Если интернет не работает, закройте программу через значок замка на панели задач и выберите другую стратегию
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- Проверьте, что в service.bat параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Используйте инструкцию из https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё остаётся среди служб

1. Узнайте имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активнее с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ уже работал.
- См. также [#251](https://github.com/IndustrialAxe/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord
- Проверьте, помогла ли очистка кэша в приложении Discord
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, используйте её
- Если сайт тоже не открывается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/IndustrialAxe/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/IndustrialAxe/tg-ws-proxy)
- Либо воспользуйтесь бесплатным MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно помогает следующая последовательность:
- обновите ipset через `service.bat` и включите `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учитывайте, что `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно: определите IP-адреса игры и внесите их в `ipset-all.txt`

Если и это не помогло, создайте обсуждение в разделе [Discussions](https://github.com/IndustrialAxe/zapret-discord-youtube/discussions), а не issue, и дождитесь ответа других игроков.

### Ответа на проблему здесь нет

- Опишите её [в этом разделе](https://github.com/IndustrialAxe/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Список ресурсов для обхода расширяется через следующие файлы:
- **`list-general-user.txt`** - домены, включая их поддомены
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP-сеть уже есть в `ipset-all.txt`, но отдельный домен фильтровать не требуется
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети для исключения
  - Файлы **`*-user.txt`** автоматически появляются при первом запуске `zapret` или `service.bat`
