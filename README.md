> [!WARNING]

> ### Реакция антивирусов
> Антивирус может отреагировать на WinDivert.  
> Этот инструмент перехватывает и фильтрует трафик, поэтому он нужен для работы zapret.
> WinDivert способен применяться как безопасными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Некоторые антивирусы классифицируют файлы WinDivert как потенциально опасные или относят их к хакерским инструментам. В результате файл может быть удалён и помещён в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений предпочтительно добавить исключение; если вы не полностью понимаете последствия, отключите обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и укажите URL вручную. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы; инструкция находится [здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 рекомендуется использовать этот способ.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут нарушиться.

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/IndustrialAxe/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открываемых через 7-Zip или PeaZip, этот пункт можно не выполнять.

4. Извлеките файлы в путь без кириллицы и специальных символов.

5. Запустите нужный файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> подходящую стратегию.

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящий вариант**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск Windows (`services.msc`).</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После смены режима стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** включает или отключает обработку сервисов из `ipset-all.txt`.  
  Это удобно при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках показывается состояние:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP проверяется по списку
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** заменяет выбранный активный фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапной остановке работы приложения.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`.
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не видно

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться `winws.exe` (обход), видимый на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/IndustrialAxe/zapret-discord-youtube/issues/522).

### Рабочей стратегии нет
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Веб-версия Telegram не подключается
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора.
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный блок.
  - Сохраните файл и проверьте подключение. При отсутствии результата убедитесь, что изменения действительно сохранились.

#### Результат не гарантируется. Если веб-версия не заработала, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/IndustrialAxe/tg-ws-proxy) или любым публичным прокси.

### Обход перестал работать

> [!IMPORTANT]
> **Стратегия, которая работает сейчас, со временем может перестать работать.**
> Её могут обнаружить, поэтому стабильность конкретного варианта не гарантируется.
> В репозитории есть много стратегий обхода. Если ни одна не подходит, создайте новую на основе существующей и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте отсутствие ошибок.

- Убедитесь, что адрес ресурса присутствует в списке доменов или IP-адресов.

- Проверьте остальные стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительные сведения есть в [#765](https://github.com/IndustrialAxe/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление
- Сохраните ресурсы и данные, добавленные вами вручную.
- Перезагрузите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите каталог zapret.
- Загрузите последнюю версию (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/IndustrialAxe/zapret-discord-youtube/releases).
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, включите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- По очереди запускайте разные скрипты `general`. После каждого проверяйте ресурсы; если доступ не восстановился, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск: `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтр может затронуть неожидаемые ресурсы.

### Античит сообщает о WinDivert

- Воспользуйтесь инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся в службах

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- См. также [#251](https://github.com/IndustrialAxe/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте Discord после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не работает и в браузере, повторно проверьте все стратегии: YouTube и Discord могут требовать разные варианты.
- См. также [#252](https://github.com/IndustrialAxe/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/IndustrialAxe/tg-ws-proxy).
- Либо используйте бесплатные MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Универсальная последовательность действий:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/IndustrialAxe/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблема не описана

- Сообщите о ней [здесь](https://github.com/IndustrialAxe/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Списки обхода можно дополнить собственными адресами:
- **`list-general-user.txt`** предназначен для доменов; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** исключает домены. Это пригодится, например, если IP-сеть есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не нужно.
- **`ipset-all.txt`** содержит IP-адреса и подсети.
- **`ipset-exclude-user.txt`** исключает IP-адреса и подсети.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
